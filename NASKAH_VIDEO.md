# NASKAH VIDEO DEMONSTRASI TUGAS PRAKTIK 2
# Aplikasi Kasir Restoran Sederhana (Java Swing GUI)
# Durasi maksimum: 15 menit

## PENUTUP AWAL (0:00 - 1:00)
[Wajah mahasiswa terlihat jelas di layar]

"Assalamualaikum warahmatullahi wabarakatuh. Nama saya [NAMA LENGKAP], NIM [NIM], Program Studi [PRODI], mata kuliah STSI4201 Pemrograman Berbasis Desktop. 

Pada video ini saya akan mendemonstrasikan pengerjaan Tugas Praktik 2, yaitu membuat aplikasi kasir restoran sederhana menggunakan bahasa Java dengan antarmuka grafis Swing. Aplikasi ini mencakup fitur pemesanan pelanggan, perhitungan total biaya dengan diskon dan promo, pencetakan struk, serta manajemen menu untuk pemilik restoran."

## PENJELASAN SINGKAT TUGAS (1:00 - 2:00)

"Tugas ini memiliki beberapa indikator: implementasi tipe data, variabel, identifier, dan keyword pada class, object, dan method; penggunaan Array dan String dalam method; struktur keputusan seperti if, if-else, if-else if, nested if, dan switch case; serta struktur perulangan for, for-each, while, dan do-while."

## TAMPILAN MENU PELANGGAN (2:00 - 4:00)
[Beralih ke layar aplikasi, tab Menu Pelanggan]

"Ini adalah tampilan utama aplikasi. Di sisi kiri ada daftar menu restoran yang dikelompokkan berdasarkan kategori MAKANAN dan MINUMAN. Terdapat 4 menu makanan dan 4 menu minuman. Data disimpan dalam array Menu[20]."

[Pindah kursor ke tabel menu, tampilkan semua 8 menu]

"Menu makanan: Nasi Goreng Rp18.000, Mie Goreng Rp17.000, Ayam Bakar Rp28.000, Soto Ayam Rp15.000. Menu minuman: Es Teh Rp6.000, Es Jeruk Rp8.000, Kopi Rp10.000, Jus Alpukat Rp14.000."

## PROSES PEMESANAN (4:00 - 8:00)

"Saya akan memesan beberapa menu. Pertama, pilih Ayam Bakar, masukkan jumlah 3, lalu klik Tambah Pesanan."

[Klik Ayam Bakar, masukkan 3, klik Tambah Pesanan]

"Kedua, pilih Es Teh, jumlah 2, klik Tambah Pesanan."

[Klik Es Teh, masukkan 2, klik Tambah Pesanan]

"Ketiga, pilih Jus Alpukat, jumlah 1, klik Tambah Pesanan."

[Klik Jus Alpukat, masukkan 1, klik Tambah Pesanan]

"Tabel pesanan sekarang menampilkan 3 item dengan subtotal masing-masing. Saya juga bisa mengedit jumlah atau menghapus item jika diperlukan."

[Pilih item di tabel pesanan, klik Edit Jumlah, ubah angka]

## PERHITUNGAN TRANSAKSI (8:00 - 10:00)

"Kemudian klik Hitung Total untuk menghitung subtotal, diskon, promo, pajak, dan biaya pelayanan."

[Klik Hitung Total]

"Aplikasi menampilkan informasi: Diskon 10% aktif karena total melebihi Rp100.000, dan Promo Beli 1 Gratis 1 untuk kategori minuman aktif karena total melebihi Rp50.000 dan ada item minuman."

## STRUK PEMBAYARAN (10:00 - 11:30)

"Klik Cetak Struk untuk mencetak struk pesanan lengkap."

[Klik Cetak Struk]

"Struk menampilkan: nama menu, jumlah, harga satuan, subtotal per item, total biaya pesanan, diskon, promo, pajak 10%, biaya pelayanan Rp20.000, dan total akhir pembayaran."

## FITUR PEMILIK RESTORAN (11:30 - 14:00)

[Pindah ke tab Kelola Menu (Pemilik)]

"Ini adalah tab manajemen menu untuk pemilik restoran. Di sini pemilik dapat melihat daftar menu, menambah menu baru, mengubah data menu, dan menghapus menu."

## TAMBAH MENU BARU (11:30 - 12:30)

"Saya akan menambah menu baru. Klik Tambah Menu Baru, masukkan nama, kategori, dan harga."

[Klik Tambah Menu Baru, isi data, konfirmasi Ya]

"Menu baru berhasil ditambahkan dan muncul di daftar menu."

## UBAH MENU (12:30 - 13:30)

"Saya akan mengubah menu yang sudah ada. Pilih menu, klik Ubah Menu Terpilih, ubah nama, kategori, dan harga, lalu konfirmasi Ya."

[Pilih menu, klik Ubah, ubah data, konfirmasi Ya]

"Data menu berhasil diubah dan tampilan tabel diperbarui."

## HAPUS MENU (13:30 - 14:30)

"Terakhir, saya akan menghapus menu. Pilih menu, klik Hapus Menu Terpilih, dan konfirmasi Ya."

[Pilih menu, klik Hapus, konfirmasi Ya]

"Menu berhasil dihapus dari daftar. Jika konfirmasi Tidak, maka data tidak berubah."

## PENJELASAN STRUKTUR CLASS (14:30 - 15:00)

"Secara singkat, aplikasi terdiri atas 5 class: Menu (data menu), ItemPesanan (satu baris pesanan), Pesanan (daftar pesanan dengan array), Struk (perhitungan dan struk), dan MainGUI (antarmuka Swing). Semua data menggunakan array, dan seluruh struktur kontrol (if, if-else, if-else if, nested if, switch case, for, for-each, while, do-while) diterapkan sesuai ketentuan tugas."

## PENUTUP (15:00 - selesai)

[Wajah mahasiswa kembali terlihat]

"Demikian demonstrasi Tugas Praktik 2. Terima kasih. Wassalamualaikum warahmatullahi wabarakatuh."
